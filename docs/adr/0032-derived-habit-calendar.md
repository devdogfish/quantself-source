# Derive Habit Stack calendar blocks from definitions

For #146 (PRD #142), day/week Habit Stack blocks derive from the current authorized Habit projection for a bounded visible date range. They create no tasks or stored calendar events: definitions remain authoritative, and blocks honor build Habit activity, start dates and schedules. Clock anchors and durations are required; cue-only and break-only groups produce no blocks. A separate read-only lane keeps task dragging and capacity calculations independent. Clicking opens the same stack quick-log and shared optimistic occurrence commands used by `/habits`.

Alerts remain disabled unless a stack or eligible tracked Habit explicitly opts in. The existing push worker, enabled settings, device registry and atomic receipt leases deliver them at America/Halifax wall times. Stable target/date/anchor receipt keys survive DST and retries; bulk observations suppress empty or fully logged stacks, with another coalesced observation check after claiming. Both declarative push navigation and service-worker clicks open the dated stack quick-log without action buttons. Stale definitions suppress reminders; live phone delivery is a deployment release check.
