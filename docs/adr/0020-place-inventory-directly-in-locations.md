# Place Inventory Directly in Locations

An Inventory Placement may target an Inventory Location directly or a Container within a location. Wardrobes, closets, refrigerators, pantries, and open storage are real retrieval destinations rather than fake containers or unplaced notes; containers remain optional finer-grained holders. Inventory Locations appear as retrieval information after product-first search, not as a separate location-browsing page. The existing visual Container page remains a deliberate exception and keeps showing only real Containers.
